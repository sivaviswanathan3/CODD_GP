# CODDGP – Flutter Web Application

A professional Flutter-based web application developed during my internship at GODDGP.
This project demonstrates Flutter web development, responsive UI design, authentication flow, and modern application structure.

 **Project Overview**

CODDGP is a Flutter web application created as part of my internship work at GODDGP.
The application includes a login system, responsive user interface, and web deployment support.

The project was developed to enhance practical knowledge in:

* Flutter Web Development
* UI/UX Design
* Authentication Screens
* Responsive Layouts
* GitHub Deployment
* Web Application Hosting

## Technologies Used

* Flutter
* Dart
* Firebase / Web Hosting
* GitHub Pages
* Material UI

## Features

* User Login Interface
* Responsive Web Design
* Fast Flutter Web Rendering
* Cross Platform Support
* Clean UI Structure
* Modern Navigation Flow
